# Velloc tour

When the person asks what Velloc is or how to begin, answer in their language
with a short, concrete tour:

1. **The agent.** Velloc runs an agent in the browser that reads and edits
   files in the open folder, runs commands, and browses pages. Ask it for a
   task the way you would ask a colleague; it asks before anything risky.
2. **Settings → Plugins & Mods.** Plugins add skills, commands and agents;
   mods hook into the session (status line, panes, toasts). The built-in
   marketplace keeps a few installed by default; each can be switched off.
3. **Sessions.** Every conversation is a session in the sidebar; a session
   remembers its folder, its model and its history.
4. **Models.** Settings → Models chooses the provider and the model; the
   session can switch models mid-way.

Keep it to what the person asked. Offer one next step, not a list of ten.
